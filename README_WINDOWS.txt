Venn Ledger - Windows Setup

To use the AI Import features, you must have Ollama installed locally.
Venn Ledger will automatically spin up the AI engine in the background when the app starts, so you only need to perform this setup once!

1. Download and install Ollama Desktop from ollama.com

2. Open your Command Prompt and run the following command to download the model:
   ollama pull mistral:7b

3. Run Venn Ledger! (The app will automatically manage the AI engine).
