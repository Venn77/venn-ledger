Venn Ledger - Linux / Steam Deck Setup

To use the AI Import features, you must have Ollama running locally.

1. Install Ollama by opening your terminal (Konsole) and running:
   curl -fsSL https://ollama.com/install.sh | sh

2. Download the required AI model by running:
   ollama pull mistral:7b

3. Run Venn Ledger!
